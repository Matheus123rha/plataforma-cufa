# Cadastro Fácil — CUFA Esteio

## Sobre o projeto

O Cadastro Fácil é um projeto de back-end que busca facilitar as inscrições nos cursos da CUFA Esteio. A ideia é criar uma API integrada ao WhatsApp para que as pessoas possam consultar cursos e se inscrever de forma simples, por meio de mensagens de texto.

## Objetivo do MVP

Criar uma versão inicial do sistema que permita consultar cursos disponíveis, realizar inscrições e controlar as vagas de cada turma.

## Funcionalidades principais

- Listar cursos disponíveis e suas vagas.
- Receber e validar os dados dos candidatos.
- Registrar inscrições no banco de dados.
- Evitar inscrições duplicadas e controlar o limite de vagas.
- Integrar o sistema ao WhatsApp para facilitar as inscrições.

## Tecnologias previstas
